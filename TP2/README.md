## Resumo
O trabalho desta semana consiste em criar em Python um pequeno conversor de MarkDown para HTML para os seguintes elementos:
- Cabeçalhos;
- Negrito (Bold);
- Itálico;
- Lista Numerada;
- Link;
- Imagem.

Para cada elemento foram criadas expressões regulares para identificar a estrutura em Markdown.

Em seguida, criei funções auxiliares associadas a cada expressão regular. Cada função é responsável por estruturar o conteúdo capturado pelos grupos no formato HTML.
